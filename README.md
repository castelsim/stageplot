# StagePlot

Editor gratuito, in italiano, per disegnare lo stage plot in scala e ricavarne scheda tecnica, channel list, monitor, schema elettrico e rider tecnico in PDF. Funziona nel browser, senza registrazione e senza filigrana.

- Sito e editor: https://stageplot.it
- Cos'è uno stage plot: https://stageplot.it/guida/cos-e-uno-stage-plot/
- Come fare uno stage plot: https://stageplot.it/guida/come-fare-uno-stage-plot/
- Rider tecnico e scheda tecnica: https://stageplot.it/guida/rider-tecnico/
- Modello di scheda tecnica in PDF: https://stageplot.it/guida/scheda-tecnica-band/

Creato da Simone Castellan, sound engineer ([simonecastellan.com](https://simonecastellan.com)).
